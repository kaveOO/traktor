# 03: Licence review (brief 5.2–5.3, Regulamin §2 ust. 10)

Scope: `main` plus lanes in `../traktor-wt2/*` (docs, engine, report, satellite, ui), checked 2026-11-22, read-only.
npm licences come from `node_modules/*/package.json`. Service terms are my reading of each provider's published terms and were **not re-fetched in this review**, so check the rows marked (verify) against the live terms page before submission.
Risk: **H** = blocks transfer to KOWR or breaks terms now · **M** = fine for the hackathon, needs a decision before KOWR production · **L** = attribution or notice only.

## Bottom line
- **No npm package is copyleft or non-commercial in a way that conflicts with assigning our code to KOWR.** Everything in the tree is permissive (MIT, ISC, Apache-2.0, BSD, CC0, 0BSD, BlueOak). The exceptions are weak copyleft (MPL-2.0, LGPL-3.0), and they only apply to unmodified build or runtime binaries.
- What KOWR receives is **our** code. Third-party components keep their own licences, so we need a `THIRD_PARTY_NOTICES` file and a source/licence register in the docs (§2 ust. 10).
- The service-level problems are **Open-Meteo** (free tier is non-commercial), **EOX hosted tiles** (the service has its own terms, and later vintages are NC-SA), **Google Map Tiles** (paid, our API key, logo rules) and **IUNG** (no explicit open licence). Each needs a production decision.
